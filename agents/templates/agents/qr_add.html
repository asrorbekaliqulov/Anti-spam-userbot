How to link a new agent
  1. On the phone with the userbot account, open Telegram.
  2. Go to Settings → Devices → Link Desktop Device.
  3. Point the camera at the QR code on the left.
  4. The session is captured automatically and saved as an active agent.
The QR token expires roughly every 30 seconds and is refreshed for you automatically. No SMS code is required.
